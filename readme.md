---
### Описание:
Реализовать REST API для реализации Библиотеки.
Для хранения данных использовала JSON файл

---
### Возможности:
- Добавлять книгу
- Удалять книгу
- Помечать как прочитанную
- Получить книгу по ID
- Получить список всех книг
- Фильтрация книг по флагу "completed"
