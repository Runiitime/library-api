### Описание:
Реализовать REST API для реализации Библиотеки.
---
### Возможности:
- Добавлять книгу
- Удалять книгу
- Менять статус completed
- Получить книгу по ID
- Получить список всех книг
- Фильтрация книг по флагу "completed" или "author"
